How to Create Shortcuts

Master r/ links in 60 seconds — live demos, no screenshots.

Static: Always goes to the same URL. Perfect for docs, dashboards, and team pages.
  1. 1

    Click New Shortcut

    On the dashboard, top right.

  2. 2

    Pattern: google

    Unique, lowercase, no spaces. Try eng/handbook for teams.

  3. 3

    Type: Static

    Auto-detected when target has no { } or [ ].

  4. 4

    Target: https://google.com

    Must start with https://.

  5. 5

    Create → r/google works!

    Share r/google in Slack — everyone lands on Google.

Dynamic: {param} is filled from the URL path.
  1. 1

    Pattern: jira

    Short, memorable.

  2. 2

    Target: https://jira.company.com/browse/{ticket}

    Use {ticket} for the variable.

  3. 3

    Visit: r/jira/PROJ-123

    → …/browse/PROJ-123. Try any ticket!

  4. 4

    Multiple: {org}/{repo}

    Maps path segments in order.

User Dynamic: [param] saved per browser.
  1. 1

    Target: https://github.com/pulls?q=author:[username]

    Square brackets = per-user.

  2. 2

    Add description: [username] → “Your GitHub username”

    Helps teammates know what to enter.

  3. 3

    First visit: prompt → saved in localStorage

    Never leaves your browser. Clear anytime.

  4. 4

    Next visits: auto-filled, no prompt

    Update at /admin/setup → Clear.
