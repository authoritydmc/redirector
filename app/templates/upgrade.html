4 If it broke, roll back

Restore an archive. Do not run flask db downgrade — it inverts a migration and can drop columns that hold your shortcuts. 

{% if info and info.data.in_docker %}docker compose down
docker compose run --rm --no-deps app \
  python -m app.utils.backup restore /app/data/backups/<name>.zip
docker compose up -d{% else %}# stop the service, then:
python -m app.utils.backup restore data/backups/<name>.zip{% endif %}

A safety snapshot of the current state is taken first, so the restore is itself reversible.
