Backup & Restore

A backup is a single .zip containing the database, the configuration (including your admin password and MFA secrets) and the install state. Restoring it puts all three back together and then runs any migrations that are still outstanding.

Restore from an archive

Restoring overwrites the current database and configuration. A safety snapshot of the present state is taken first, so this is reversible.

The restore is applied on the next start, not immediately: the running process cannot replace the database it is serving from.

How the restart is done per platform

Docker: docker compose restart app or docker restart redirector

Windows (service): Restart-Service Redirector

macOS (launchd): launchctl kickstart -k gui/$(id -u)/com.authoritydmc.redirector

Linux (systemd): sudo systemctl restart redirector

State file: .redirector-state.json · Upgrade guide: /upgrade
