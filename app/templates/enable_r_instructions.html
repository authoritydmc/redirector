Just for me — hosts file

30 sec
1

Open PowerShell as Administrator

Hit Win, type PowerShell, right-click → Run as Administrator. Click Yes.

2

Run the script (copy & paste)

powershell -ExecutionPolicy Bypass -Command "Add-Content -Path $env:windir\System32\drivers\etc\hosts -Value '127.0.0.1   r' -Force; Write-Host 'Done! Try r/docs in your browser.'"

Or download and double-click: add-r-host-windows.ps1

3

Verify — open http://r/

Should show Redirector. If you see a search page, fully close and reopen your browser.

Troubleshooting Windows
  • Access denied: You must run PowerShell as Administrator.
  • Still not working: Run ipconfig /flushdns then restart Chrome.
  • Antivirus blocks hosts: Allow the edit or add 127.0.0.1 r manually via Notepad as Admin.

FAQ

Is it safe? Can I undo it?

Yes — it only maps r to your own machine (127.0.0.1). Delete the line from your hosts file to undo. No data leaves your device.

r/ shows my search engine, not Redirector

Fully quit your browser (not just close tab) and reopen. Chrome sometimes caches the old non-existent host. Also clear `chrome://net-internals/#dns` → Clear host cache.

Can I use go/ instead of r/?

Yes — add 127.0.0.1 go as well, or set hostnames in data/redirect.config.json. Then use go/docs.

Company wants r.company.com not plain r

Works too — just use DNS for r.company.com and set that as your redirector's public URL. Short links become r.company.com/docs.
