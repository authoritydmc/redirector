Engineered For Teams

Everything You Need In An Enterprise Redirector

Packed with thoughtful features for corporate networks, DevOps teams, and developers — without the per-seat SaaS bill.

Dynamic & User Shortcuts

Placeholders like r/jira/{ticket} and personal variables like r/github/[user] stored in localStorage.

Redis-Speed Caching

In-memory resolution with automatic invalidation on edits. Hot shortcuts resolve in under 2 ms without touching the database disk.

Upstream Checking & Fallback

Check external shorteners (Bitly, go-links, internal tools) in real time over SSE. Found upstream links are cached automatically.

SSO Protection & Security

Detects Okta, Google and Microsoft SSO auth URLs to prevent stale token caching, with safe-target validation against open redirects.

Two-Factor Auth & Passkeys

Guard admin operations with TOTP authenticator apps, backup codes and WebAuthn hardware biometric passkeys.

Instant QR Codes

High-resolution QR for every link via r/qr/{pattern} — perfect for slides, posters and badges.

Backup & Restore

One-click zipped snapshots of database, config and state. Stage a restore safely — it applies on next start, never mid-traffic.

Metrics That Matter

Team KPI dashboard, live resource graphs, cache hit-rates and Prometheus endpoints — prove adoption to leadership.

Adaptable Deployments

Built For Every Workflow

Internal Company-Wide DNS

Configure an internal DNS record mapping r or go to your Redirector instance. Every employee can access r/zoom, r/standup, or r/handbook right from their browser bar without extensions.

r.corp.local  IN  A  10.0.1.50

Engineering & Issue Trackers

Create parameterized shortcuts for Jira, Linear, and GitHub. Typing r/jira/PROJ-102 or r/gh/redirector automatically expands into deep ticket and repository URLs.

r/jira/{ticket} -> https://company.atlassian.net/browse/{ticket}

Local Workstations & Power Users

Run locally in a minimal Docker container. We provide one-liner scripts for macOS, Windows PowerShell, and Linux that automatically register 127.0.0.1 r in your hosts file.

powershell -ExecutionPolicy Bypass -File .\add-r-host-windows.ps1

Reverse Proxy Coexistence

Deploy cleanly behind Traefik, Caddy, or Nginx with standard HTTPS termination. Integrates with existing corporate redirectors so you can safely migrate without broken bookmarks.

proxy_pass http://127.0.0.1:8080;

Questions, Answered

Frequently Asked Questions

Is Redirector really free?

Yes — open-source under MIT/Apache-2.0. Run it on a $5 VPS or your existing intranet server. No seats, no tiers, no link limits.

Where does my data live?

In one data/ directory on your server — database, config, install state and backups. Atomic writes plus a backup copy mean an unclean shutdown can't corrupt it. Nothing phones home.

Do I need Redis or Postgres to start?

No. SQLite plus built-in caching works out of the box. Add Redis for sub-2 ms hot-path resolution and Postgres for large-team concurrency when you grow — the same compose file supports both.

How does SSO and MFA work?

SSO login URLs (Okta, Google, Microsoft) are detected and never cached as shortcuts. Admin actions are guarded by TOTP authenticator apps, hashed backup codes and WebAuthn passkeys.

Can we migrate from go/links or Bitly?

Yes. Upstream checking resolves your existing intranet and public shorteners with real-time logs and caching, and signed JSON import/export moves your link library with integrity verification.

What happens if the server restarts mid-upgrade?

Entrypoint guards refuse to run an older image against newer data, auto-snapshot before migrations, and apply staged restores before booting — upgrades are boring on purpose.
